# TENZU 建築図面スタジオ

TENZUは、建築CADに慣れていない人が展示やイベントのアイデアを3Dで試し、関係者に伝わる図面のたたき台にするためのツールです。Room Studioで作った会場・展示の3D配置を読み込み、平面図・立面図・断面図・詳細図・消防確認用シートをまとめて出力できます。

## 役割分担

| 段階 | 使うもの | 目的 |
| --- | --- | --- |
| アイデアを考える | スケッチ、文章、画像など | 展示の体験、必要なもの、来場者の動きを決める |
| 3Dで試す | Room Studio | 会場や展示物を簡易モデルで置き、配置・高さ・見え方を検討する |
| 図面のたたき台にする | TENZU | Room StudioのJSONから複数の図面シートを作り、寸法や確認事項を共有する |
| 清書・確認する | 建築CAD、設計者、施工者、施設担当者など | 公式資料との照合、施工用図面の清書、安全性・法令・施設条件の確認を行う |

TENZUはCADの代替や申請図の自動認証ツールではありません。最初の案を早く見える形にし、専門家や施設担当者と具体的に相談するための橋渡しとして使います。

## はじめての使い方

1. **まずアイデアを整理します。** 何を展示するか、必要な壁・什器・作品、入口と出口、来場者の流れを箇条書きや手描きでまとめます。
2. **Room Studioで簡易3Dを作ります。** 会場の形と展示物を配置します。可能な範囲で実寸を入力し、仮の寸法や未確認の設備には名前で「仮」「要確認」と付けてください。初期案は細部より、全体配置と高さが伝わることを優先します。
3. **Room StudioからJSONを保存します。** TENZUに読み込むのはRoom StudioのシーンJSONです。画像、PDF、GLB、Room StudioのHTMLファイルではありません。
4. **TENZUでJSONを読み込みます。** 公開ページ上部の「Room Studio JSONを開く」を押し、保存したJSONを選びます。読み込みに失敗したら、Room StudioからJSON形式で保存し直したファイルか確認してください。
5. **図面目録と確認事項を見ます。** まずS-00で寸法・形状の注意点を確認し、S-01で公式図面の準備から現場確認までの手順を確認します。
6. **各図面シートを確認します。** 左の目録または上部のタブでシートを切り替え、レイヤーを表示・非表示にします。平面図ではオブジェクトを選択すると、位置や変換後メッシュ外形を確認できます。必要な場合は右側のΔX・ΔZで、図面プロジェクト上の位置を微調整します。この補正はRoom Studioの元ファイルには書き戻されません。
7. **表題欄を入力します。** 右側でプロジェクト名、作図者、日付を設定すると各シートに反映されます。
8. **PDFまたはSVGを出力します。** 「このシートを印刷」で表示中の1枚を印刷し、「図面を印刷 / PDF」で全シートを印刷できます。ブラウザーの印刷画面でPDF保存を選び、A3横・倍率100%を基本にします。既知寸法を複数箇所で確認し、ページに合わせる等の自動縮小が入っていないか確認してください。「SVG出力」は表示中のシートを書き出します。
9. **たたき台を清書担当へ渡します。** Room Studioの元JSON、TENZUの図面PDF、公式の平面図・消防設備図、未確認事項の一覧をまとめて渡します。CADでの清書と、寸法・施工・安全・施設条件の最終確認は専門担当者と行います。

## 出力されるシート

| 図番 | 内容 |
| --- | --- |
| S-00 | 概要・図面目録・モデルの照合事項 |
| S-01 | 作図順序・現場確認チェックシート |
| A-01 | 会場平面図・配置図 |
| A-02 | 立面図・断面図 |
| A-03 | 3Dアクソメ参考図 |
| A-04 | 大木・布・仕切りのオブジェクト詳細図 |
| A-05 | 什器・作品の配置とRoom Studio抽出外形一覧 |
| E-01 | 照明・電源の入力状況と確認項目 |
| F-01 | 避難動線案・出口候補の検討図 |
| F-02 | 既存消防設備と展示計画の干渉確認用シート |

## できること

- Room StudioのシーンJSONを読み込み、会場輪郭やオブジェクトの位置・外形を図面に反映する
- 平面・立面・断面・詳細・3Dの図面シートを表示する
- 建築・展示壁・布・大木・その他オブジェクト・人物ダミーの表示レイヤーを切り替える
- 平面図で選んだオブジェクトの変換後外形を確認し、図面上のX/Z位置を補正する
- 図面名欄を編集し、表示中のシートをSVG出力、または図面一式をA3横PDFとして印刷する
- 作業中の補正や表題欄を含むTENZUプロジェクトJSONを保存する

## 現時点でできないこと

- TENZU上で壁や什器を一から描いたり、Room Studioの寸法・形状を編集して元データに戻したりすること
- 公式PDFを下図として読み込み、画面上で縮尺校正すること
- 消防設備、照明、コンセント、配線の実位置を自動で取り込むこと
- 避難距離・通路幅・収容人数・構造安全性・法令適合を自動判定すること

そのため、現況図や設備図は別途入手して専門担当者と照合してください。設備位置がRoom Studio JSONに存在しない場合、TENZUは推測した記号を実設備として描かず、未入力・要確認として示します。

## 図面の位置づけとデータの扱い

出力図は計画・相談・清書準備用のたたき台です。壁・開口などのサンプル形状に概算が含まれる場合があります。図面だけで施工・申請・消防協議を完了できるものではありません。現況寸法、出入口の有効幅、避難経路、消防設備、最大滞在人数、素材・防炎性能、固定方法、床荷重などを、会場管理者・建築士・施工者・所轄消防と確認してください。通路幅や催物届出の要否・期限は会場と催物の条件によって異なるため、具体的な配置で管轄窓口へ確認してください。

このページはブラウザー内で動作し、読み込んだファイルをサーバーへ送信しません。公開ページには会場レイアウトのサンプルを含みます。公開データの取り扱いは、会場管理者の許諾と公開者の判断に従ってください。
