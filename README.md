# TENZU 建築図面スタジオ

Room Studio の配置データを読み込み、会場平面図、立面図、断面図、オブジェクト詳細図、3D確認図、消防・避難計画の検討図を作成する静的Webアプリです。サンプルとして、Room Studio の実データを含みます。

## 使い方

1. [公開ページ](https://zrzrcat2003.github.io/tenzu-roomstudio-drawings/) を開きます。
2. `Room Studio JSONを開く` から `.json` ファイルを読み込みます。
3. 図面目録から見たいシートを選び、表示レイヤーや図面表題欄を編集します。工事名・作図者・日付は全シートの表題欄に反映されます。
4. `SVG出力` で表示中のシートを書き出すか、`図面を印刷 / PDF` で図面一式を出力します。
5. `プロジェクト保存` で表題欄や図面上の位置補正を含む作業データを保存できます。

このページはブラウザー内で動作する単一HTMLアプリです。読み込んだファイルをサーバーへ送信せず、編集内容はこのページのブラウザー内で扱います。

## 図面の位置づけ

掲載図面は Room Studio のシーンデータと提供資料をもとにした計画・協議用の検討資料です。壁・開口などに画像からの概算を含み、避難経路や誘導灯の表示は法令適合判定ではありません。現況寸法、出入口の有効幅、設備、最大滞在人数、素材・防炎性能、固定方法などを会場管理者、建築士、所轄消防と確認して確定してください。

## 公開データ

この公開版には会場レイアウトと避難計画の検討図が含まれます。取り扱いは公開者の判断と会場管理者の許諾に従ってください。
