# TENZU 建築図面スタジオ

 Room Studio の配置データを読み込み、会場平面図、立面図、断面図、オブジェクト詳細図、什器・作品配置図、3D確認図、消防・避難計画の検討図を作成する静的Webアプリです。サンプルとして、Room Studio の実データを含みます。

## 使い方

1. [公開ページ](https://zrzrcat2003.github.io/tenzu-roomstudio-drawings/) を開きます。
2. `Room Studio JSONを開く` から `.json` ファイルを読み込みます。
3. 図面目録からシートを選びます。表示レイヤーは EX-建築、NEW-展示壁、NEW-什器などの分類で切り替えられます。工事名・作図者・日付は全シートの表題欄に反映されます。
4. `SVG出力` で表示中のシートを書き出すか、`図面を印刷 / PDF` で図面一式を出力します。
5. `プロジェクト保存` で表題欄や図面上の位置補正を含む作業データを保存できます。

このページはブラウザー内で動作する単一HTMLアプリです。読み込んだファイルをサーバーへ送信せず、編集内容はこのページのブラウザー内で扱います。

## シート一覧

| 図番 | 内容 |
| --- | --- |
| S-00 | 概要・図面目録・照合事項 |
| A-01 | 会場平面図・配置図 |
| A-02 | 立面図・断面図 |
| A-03 | 3Dアクソメ参考図 |
| A-04 | 大木・布・仕切りの詳細図 |
| A-05 | 什器・作品の配置とRoom Studio抽出外形一覧 |
| E-01 | 照明・電源の入力状況と確認項目 |
| F-01 | 避難動線案・出口候補の検討図 |
| F-02 | 既存消防設備と展示計画の干渉確認用シート |

縮尺出力はA3横を基本にしています。モデル空間を実寸で整え、印刷前に寸法が分かる区間を複数照合してください。PDF下図を使用する場合はページ余白や拡大縮小の影響を受けるため、既知寸法で校正が必要です。

## 図面の位置づけ

掲載図面は Room Studio のシーンデータと提供資料をもとにした計画・協議用の検討資料です。壁・開口などに画像からの概算を含み、避難経路や誘導灯の表示は法令適合判定ではありません。消防設備、照明、電源などRoom Studioデータに存在しない位置情報は推測で描かず、シートに未入力として表示しています。消防設備、照明、電源などRoom Studioデータに存在しない位置情報は推測で描かず、シートに未入力として表示しています。現況寸法、出入口の有効幅、設備、最大滞在人数、素材・防炎性能、固定方法などを会場管理者、建築士、所轄消防と確認して確定してください。
